# Contributing

Thanks for your interest in contributing!

1. Fork the repository and create your branch from `main`.
2. Follow the existing code style (the project uses conventional commits, e.g. `feat:`, `fix:`, `docs:`).
3. Add or update tests where it makes sense and make sure the build passes.
4. Open a pull request describing what changed and why.

For larger changes, please open an issue first to discuss what you would like to change.
